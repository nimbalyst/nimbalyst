# Launch checklist

Use this checklist as a lightweight home for work that crosses documents, data, and design.

## Story

- [ ] Confirm the product brief names one clear audience.
- [ ] Check that every headline metric has a source.
- [ ] Review the launch-readiness note with the project owner.

## Data

- [ ] Add the latest month to the revenue spreadsheet.
- [ ] Recalculate the launch target gap.
- [ ] Investigate any unexpected change in churn.

## Design

- [ ] Review the dashboard at a narrow width.
- [ ] Check that labels remain readable in the embedded view.
- [ ] Capture decisions that change the scope.

## Release

- [ ] Triage open tracker items.
- [ ] Assign an owner to every launch blocker.
- [ ] Write a short update for the team.
