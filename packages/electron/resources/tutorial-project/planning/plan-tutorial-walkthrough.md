# Tutorial walkthrough

## Goal

Help a new user discover that a Nimbalyst project can hold connected documents, data, visual designs, and tracked work without requiring a rigid setup.

## Walkthrough

- [x] Start with a welcoming project hub.
- [x] Open a spreadsheet and inspect the source data.
- [x] Change an assumption in the metrics model.
- [ ] Compare the embedded dashboard with its full editor.
- [ ] Follow a tracker reference back to this plan.
- [ ] Use an agent session to refine one project artifact.

## Success criteria

The walkthrough succeeds when a new user can move between file types, understand why the project is structured into folders, and see that planning documents remain useful both as prose and as tracker items.
