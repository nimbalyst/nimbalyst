# GPT Live voice previews

The desktop picker plays bundled recordings generated by `gpt-live-1` with the selected `audio.output.voice`. Recordings use one English phrase for comparison; they are not TTS substitutes. Vite imports the MP3 files into the renderer build, so preview playback works offline without an API key.

To regenerate, run the repository's Electron executable with `scripts/voice-previews/record-live.cjs`, an explicit Nimbalyst user-data directory, a fresh output directory, and optionally voice names. The script reads only the configured global OpenAI credential from the encrypted vault using Electron safeStorage; it never prints or writes the key and never reads environment credentials. Generation incurs Live API usage. It creates each session sequentially, sends paced silent input, collects audio and transcript events, and requires `session.closed` before accepting a sample. A deadline terminates failed sessions.

The script rejects transcripts that differ from the sample phrase and verifies the resolved model and voice. FFmpeg trims surrounding silence and encodes mono 24 kHz MP3 at 96 kbps, without changing speed or pitch. Listen to replacement recordings before publishing them. Copy accepted MP3s into the renderer's `assets/voice-previews/gpt-live-1` directory and update its recording manifest with the generation metadata and file hashes. Keep the picker catalog and `liveVoicePreviews.ts` aligned.

Protocol references: [Live WebSockets](https://developers.openai.com/api/docs/guides/voice-websockets?api=live) and [Live session greetings](https://developers.openai.com/api/docs/guides/live-conversations#greet-before-the-caller-speaks).
